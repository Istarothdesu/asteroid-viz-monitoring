# 小行星动态展示

这是一个在浏览器中运行的小行星信息展示项目。你可以像查看地图一样，在三维画面中寻找小行星、查看它们的运动路线，并了解它们何时会接近地球。项目也展示观测站和模拟观测任务，方便按时间回放整个过程。

项目名称：`sta-intra`。

## 可以做什么

- **浏览三维场景**：查看太阳、行星、月球和小行星，点击目标查看详情。
- **查看接近地球的事件**：按时间和条件筛选事件，打开详情了解接近时间、距离等信息。
- **拖动时间轴**：暂停、加速或倒放，观察天体位置如何变化。
- **查看观测任务**：浏览地面观测站，以及用于展示的空间观测计划和任务回放。
- **搜索与学习**：搜索目标或事件；在“知识库”中查看页面里用到的概念说明。

### 数据说明

项目使用公开的小行星和接近地球事件数据，也包含为了展示流程而生成的模拟事件、空间观测计划和本地计算结果。页面会尽量标明数据来源和模拟状态。**模拟结果和本地风险分析仅供学习、展示和辅助理解，不能当作官方预警结论。**

仓库自带一份初始数据库，因此在不联网同步数据时，也可以浏览已有内容。联网后可按项目设置更新公开数据。

## 在电脑上运行

先从 GitHub 下载项目 ZIP 并解压，或使用 Git 克隆仓库：

```bash
git clone https://github.com/Istarothdesu/asteroid-viz-monitoring.git
cd asteroid-viz-monitoring
```

需要提前安装：

- Node.js 22 或更新版本
- pnpm 9 或更新版本
- Python 3.12 或更新版本
- [uv](https://docs.astral.sh/uv/)（用于安装和运行 Python 依赖）
- 支持 WebGPU 的现代浏览器（用于显示三维场景）

打开两个终端，都先进入解压或克隆后的项目文件夹。

**终端一：启动后端**

```bash
cd backend
uv sync --extra dev
uv run uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

**终端二：启动前端**

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

然后在浏览器打开 <http://127.0.0.1:5173>。后端运行在 <http://127.0.0.1:8000>；前端开发服务会自动把数据请求转发给后端。

如果只想使用仓库里已有的数据，可以在启动后端前关闭联网同步：

```powershell
# Windows PowerShell
$env:SYNC_ENABLED = "false"
uv run uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

```bash
# macOS / Linux
SYNC_ENABLED=false uv run uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

## 第一次使用

1. 打开“实时态势”，用鼠标拖动和缩放三维画面，点击小行星查看信息。
2. 打开“事件中心”，选择一个接近地球的事件，进入详情页查看时间、距离和动态展示。
3. 拖动底部时间轴，观察事件发生前后画面的变化。
4. 打开地面监测或空间观测页面，查看观测站和模拟任务；遇到不熟悉的词，可以打开“知识库”。

## 使用 Docker 运行

如果已经安装 Docker，也可以在项目根目录运行：

```bash
docker compose up -d --build
```

完成后打开 <http://127.0.0.1:8000>。Docker 会把前后端打包到一起，并用数据卷保存运行数据。构建镜像时需要能下载前后端依赖；更详细的交付步骤见 [DEPLOY.md](./DEPLOY.md)。

## 常见问题

- **三维画面是黑的**：确认浏览器和显卡支持 WebGPU，并尝试更新浏览器或显卡驱动。
- **页面有画面但没有数据**：确认后端终端仍在运行，并访问 <http://127.0.0.1:8000/health> 检查服务状态。
- **离线时看不到最新事件**：关闭联网同步后只能使用本地已有数据；需要新数据时再开启同步。

项目代码主要位于 `frontend/`（页面与三维展示）和 `backend/`（数据接口与计算）。
